## 🌐 1-Click Free Deployment

You can host this live on the web for free:

### Option A: Vercel (Recommended)
1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Select your repository. Framework preset will automatically detect **Vite**.
4. Click **Deploy**. Your site is now live on `https://your-project.vercel.app`!

### Option B: Netlify
1. Run `npm run build`
2. Drag and drop the `dist/` folder directly onto [app.netlify.com/drop](https://app.netlify.com/drop).
